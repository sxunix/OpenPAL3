# 战斗特效：技能 / 道具 → 特效组

来源 `PAL3_unpacked.exe`（`D:\Project\PAL3\combat\CBStageEffect.cpp`、`EffMgr.cpp`）。
移植在 `yaobow/shared/src/openpal3/combat/linker.rs`，接入在 `commands/combat.rs::drive_staging`，
特效组本身的解析 / 渲染见 `flexeff_format.md` 与 `openpal3/scene/flexeff_*.rs`。

## 1. `cbdata\efflinker.dat`：384 × 60

`FUN_00508e30` 读 0x5a00 字节进 CBStageEffect `+0x98c`（`FUN_00508f30` 是写回，编辑器用）。
`FUN_00508880(id)` 线性查，查不到就占一条 id == 0 的空位。

| 偏移 | 含义 |
|---|---|
| +0x00 | id |
| +0x04 | 第一段特效组（-1 无） |
| +0x08 | 第一段挂点四字节 |
| +0x0c | 挂点全 0 时的坐标 |
| +0x18 | 第一段起播时刻 |
| +0x1c | **结算时刻**（道具编排 `FUN_00500550` 到点才 `FUN_004ef8b0`） |
| +0x20 / +0x24 / +0x28 / +0x34 | 第二段：特效组 / 挂点 / 坐标 / 起播时刻 |

id 的归属（拿 gdb 逐个对）：**187 个技能全部在表里**，59 个可投掷道具（61xx「梅花镖」
「袖箭」…），另有 501..510 十条对不上数据库；128 条 id 为 0 的空位。结算时刻分布：
2.0 秒 94 条、1.5 秒 87 条、0 秒 29 条、1.8 / 1.0 / 0.5 / 0.25 / 11 秒若干。第二段只有
1 条在用（2215 → 组 7）。

挂点（`FUN_00508930`，四个字节依次覆盖，最后置位的算数）：

| 字节 | 挂在哪 |
|---|---|
| 0 | 出手这一方的定点：我方 → CBStage `+0x384..+0x38c`，敌方 → 10 号位舞台角色的位置 |
| 1 | 目标那一方的定点（按目标在哪边；打整边时按技能种类判） |
| 2 | 出手的人（舞台角色 `+0x19c4`） |
| 3 | 目标（打整边退回目标那一方的定点） |
| 全 0 | 记录里的坐标 |

实机：字节 3 置位 121 条、字节 1 置位 47 条、全 0 88 条。

行动码 0x10d / 0x10e 播之前还会 `FUN_004ce460` 预载一次。

## 3. 特效里的镜头

特效类 `camera`（15 类里的第 4 类，11 条定义）由 `FUN_004c39a0` 驱动：开始时停掉当前镜头
序列，若自身一个 float 字段 > 0 就 `FUN_00505770(round(它))` 播那个 flexcam 序列；结束时
停掉。所以**仙术的镜头不是单独排的，是跟着特效组走的**。移植端的特效播放（`adv_director`）
目前只处理 `callback` / `audio` / `quad` / `cylinder`，`camera` 还没接。

## 4. 移植端

出手条满、舞台演出手动作那一刻起计时：到第一 / 第二段起播时刻就 `play_effect(组, 挂点)`，
到结算时刻才 `strike()`（普通攻击没有链接，仍按 0.3 秒 [推断]）。挂点里「我方定点」用
0..4 号位重心代替 CBStage `+0x384` [推断]。

## 5. 现在能画出多少（2026-09-11 统计）

顶层特效组几乎都只有 `callback` + `audio`（比如 413、371），画面在 callback 指向的下级组里。
**callback 子块 +0 / +32 的组号是 float**（`adv_director` 就是按 float 读的；按 i32 读会把整棵树
读成空的——统计时踩过一次）。

顺着 callback 展开到底，235 个被链接的特效组里：

- 77 组只含移植端已经会画的类（`quad` / `cylinder` / `audio` / `callback`），能完整画出；
- 137 组能画出一部分；
- 其余约 20 组一点都画不出。

展开后各类出现次数：quad 2490、cylinder 945、callback 467、meteor 254、audio 229、particle 208、
shock 98、model 67、grid 62、action 49、explosive 16、camera 13、quake 12、bink 7、time 1。

实机：夜游 / 日游出招放的是 413（展开为 meteor ×6 + particle「xue.par」），两个类都还没接，
所以画面上什么都没有；1.5 秒后按链接表的结算时刻打倒景天，时序是对的。
「烈焰燃雷」371 展开为 shock ×13 + quad「xiaozha.tga」×13 + particle「huo.par」×11，
其中 quad 那一半现在就能画。

下一步按缺口大小和难度：particle（`.par` 运行时现成）→ meteor → camera（接 flexcam）→ shock / model。
