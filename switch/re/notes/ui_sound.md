# PAL3.exe v1.4 — 界面按钮音效

原版放一次音效：`FUN_0053df70(名字, 1)` 取声音对象，`FUN_0053e2e0` 播放。名字不是直接压字符串，
而是从各模块自己的一张 `const char*` 指针表里取（`mov reg, [0x5xxxxx]`），所以按字符串地址搜调用点
搜不到，要按 `call 0x53df70` 找再往前看最近一次从指针表取值。

| 模块 | 指针表 | 音效调用所在 |
|---|---|---|
| 买卖前台菜单 | `0x5b203c` | `FUN_0045a600`（四个钮各一次） |
| 买两页 | `0x5b46b4` 起 | `FUN_0046b040` 之后的事件段（按控件 id 跳表 `0x46cf98`） |
| 卖页 | `0x5b7650` 起 | `FUN_0046f620`（跳表 `0x47099c`） |
| 冶炼 | `0x5bc90c` 起 | 页 `FUN_0047b6c0`，菜单 `FUN_0047c430` |
| 当铺 | `0x5dff88` 起 | 经营页 `FUN_0051f1b0`、切页 `FUN_00523820`、增资页 `FUN_005249a0` |

`snd\` 下的文件（22050 Hz 双声道）：wa001 0.32 s、wa002 0.20 s、wa003 0.22 s、wa004 0.32 s、wa005 0.04 s、
wa016 0.41 s、wa026 5.11 s。

## 各音效的用法（按调用点前后的分支认的）

- **wa001 普通点击**：买卖菜单四个钮；买卖子页的退出、还价、确定/取消、五个折扣档（`0x46b8dc`…`0x46bcca`）；
  卖页三处；冶炼菜单三个钮；冶炼「否」（`FUN_0047adf0` 还材料之后，`0x47b767`）；当铺切页、「经营」的级联
  开关（`0x51ffbd` 起四处）、弹完说明框之后、增资确定 / 取消（`0x524ae8` / `0x524c4f`）。
- **wa004 做不到**：当铺点了置灰的菜单钮（`test al, al` 之后，`0x51f211` 等三处）；冶炼「是」放不上材料
  （`0x47b94c`）；买卖页加减数量到头（`0x46bd9f` 那支先弹说明框、`0x46c023` 不弹）。
- **wa005 一格**：买卖页加减数量动了（`0x46bdc1` / `0x46c045`，卖页 `0x46fe4e` / `0x4700ac`）；当铺增资拖动条
  动了（`0x524ab1`）。
- **wa003 提示**：冶炼「是」放上材料（`FUN_0047aab0` 之后，`0x47b901`）；当铺进店弹红利框（`0x523c3f`）、
  增资不行时的说明框（`0x51fb23`）。
- **wa026**：冶炼开炉（`0x47ba3d`，和 `FUN_0047a400` 撒火花同一支）。
- `FUN_004593c0` / `FUN_0045a220` 里另外几处 `call 0x53df70` 取的是 `Music\PI23.mp3` 之类，是换背景音乐，
  不是按钮音。列表行和滚动条在这些页面里不放音。

## 移植端

`commands/ui_sound.rs`：`CLICK/NOTE/DENIED/TICK/FORGE` 五个常量和 `play`（放一次，音源交全局表保活）。
买卖、冶炼、当铺在动作处把要放的音记下来，处理完鼠标和按键后再放（离开钮那一下关界面前放掉）。
键盘 / 手柄按到的按钮音同鼠标。冶炼「是」几种放不上的情况都归 wa004 [推断]；当铺说明框的「确定」
放 wa001 [推断]。
