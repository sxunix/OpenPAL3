# 打苍蝇（SCE 105）——半成品笔记

还没移植。这里记的是已经读出来的部分，省得下次从头翻。地址都是 PAL3 v1.4
未加壳 `PAL3_unpacked.exe`。

## 1. 入口与对象

`LAB_004370e0`（无参数）：`FUN_0044f610(9)` 进模式 9，再挂等待任务
（`FUN_00434ca0(9)` → `FUN_00434c40`），脚本挂起到模式结束。

模式 9 的对象在 `FUN_0044f8d0` 的 `case 9` 建（`operator_new(0x89c)` +
`FUN_005295f0` 构造 + `FUN_00529870` 开局）。贴图在
`SubGame\KillFlyer\`：`Flyer_gold.tga`、`Flyer_nor.tga`、`Kill.tga`、
`Kill_pa.tga`。

## 2. 已读出来的规则

- **三只苍蝇**：构造函数 `FUN_00553627(this + 0x80, 0xb8, 3, …)` 建三个
  控件，开局那圈也是 `while (param_2 < 3)`。
- 每只开局给一个速度系数 `(rand15() % 12 − 6) * 0.1 + 0.8`（0.2–1.3），
  另存一份 `× 1.6`。
- **出苍蝇**（`FUN_0052aab0` 的 1000 分支）：先按 `rand10 < round(x*10.24)`
  掷一次（`x` 是 `__ftol` 出来的百分数，来源还没读），中了就
  `+0x69c = 1`；再掷 `rand10 < 0x66`（约 10%）→ `+0x69c = 3`。
  - `+0x69c == 3`：第一只是金苍蝇（`Flyer_gold.tga`），值
    `rand15() % 100 + 100`（100–199），其余两只是普通的
    （`Flyer_nor.tga`），值 `rand15() % 20 + 1`（1–20）。
  - 否则出 `+0x69c` 只普通苍蝇，值同上。
  - 出苍蝇时放音效 wa039。
- **要花精**：开局 `if (DAT_00c0476c < 1) 花费 = 0; else 花费 = ftol(…)`，
  至少 1（`DAT_00c0476c` 是角色 0 的当前精）。
- **收尾** `FUN_0052aa50`：
  ```text
  钱 += this+0x65c        // 这一局打出来的钱
  角色0.精 -= this+0x4e0   // 花费，扣到 1 为止
  if (this+0x164 == 2) this+0x164 = 1
  FUN_0044f610(0)          // 回去
  ```
