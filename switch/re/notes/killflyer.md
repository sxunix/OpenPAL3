# 打苍蝇（SCE 105）

Q07 / T01 / T02 的 proc 681「打苍蝇」。地址都是 PAL3 v1.4 未加壳
`PAL3_unpacked.exe`。

## 1. 入口与对象

`LAB_004370e0`（无参数）：`FUN_0044f610(9)` 进模式 9，再挂等待任务
（`FUN_00434ca0(9)` → `FUN_00434c40`），脚本挂起到模式结束。

模式 9 的对象在 `FUN_0044f8d0` 的 `case 9` 建（`operator_new(0x89c)` +
`FUN_005295f0` 构造 + `FUN_00529870` 开局）。虚表在 `0x57076c`：
`[1] = 0x529cf0` 画、`[2] = 0x529e40` 每帧、`[6] = 0x52aab0` 收事件。
贴图在 `SubGame\KillFlyer\`：`Flyer_gold.tga`、`Flyer_nor.tga`、
`Kill.tga`、`Kill_pa.tga`（后两张是拍子的两帧）。

## 2. 构造函数里的常数（`FUN_005295f0` 尾部，0x5296fd 起）

| 字段 | 值 | 是什么 |
|---|---|---|
| `+0x6ac` | `0x1c` = 28 | 苍蝇尺寸；落地线是 `场地高 − 2 × 它` |
| `+0x71c` | `1.0` | 出苍蝇的概率（**每次必出**）|
| `+0x720` | `0.69` | 未定 |
| `+0x724` | `0.1` | 出金苍蝇的概率 |
| `+0x728` | `0.01` | 下落加速度 |
| `+0x63c…+0x648` | `(0,0,800,600)` | 场地就是整屏 |

三只苍蝇：构造里 `FUN_00553627(this + 0x80, 0xb8, 3, …)`，每只的记录跨度
0xb8，第一只在 `+0x200`。

## 3. 开局 `FUN_00529870`

- 每只给速度系数 `(rand15() % 12 − 6) × 0.1 + 0.8`（0.2–1.3），另存 `× 1.6`。
- **花费**（0x529970 一段）：
  ```text
  if (角色0.当前精 < 1) 花费 = 0;
  else { 花费 = ftol(当前精 × 0.01); if (花费 < 1) 花费 = 1; }
  ```
  也就是**当前精的百分之一**，向下取整、至少 1。

## 4. 出苍蝇 `FUN_0052aab0`（事件 1000）

```text
srand(timeGetTime())
n = ftol(this->+0x71c × 100)                    // 概率，构造里是 1.0
if (rand10 < round(n × 10.24)) {                 // 必中
    this->+0x69c = 1
    if (rand10 < 102.4) this->+0x69c = 3         // 10% 出三只
    三只那一波：第 0 只是金的（Flyer_gold），值 rand15() % 100 + 100
                其余两只普通（Flyer_nor），值 rand15() % 20 + 1
    一只那一波：普通，值同上
    放音 wa039
}
```

## 5. 每帧 `FUN_00529e40`

鼠标在场地里时每 100 毫秒换一次拍子贴图（`Kill.tga` / `Kill_pa.tga`），
按下左键放拍子音效。每只苍蝇按 `+0x64c + i*4` 的状态走：

| 状态 | 行为 |
|---|---|
| 0 在飞 | 朝随机目标点挪；位置越出场地边界一次 `+0x6a0[i]` 加一，加到 **2** 就置状态 2（飞走）。鼠标压在它身上且左键按下 → 换成拍扁的贴图、状态置 1、下落速度置 `0.3` |
| 1 在掉 | `y += 速度`，`速度 += 0.01`；掉过 `场地高 − 2 × 28` → 隐藏、位置复位 (400, 300)，**这时才记分**：打死数 `+0x658` 加一、`+0x660` 加一、**钱 `+0x65c` += 这只的值 `+0x710[i]`**，状态置 3 |
| 2 飞走 | 隐藏、`+0x658` 加一、状态置 3，**不给钱** |
| 3 | 结束，跳过 |

`+0x658` 加到 `+0x69c` 就置 `+0x72c = 1`（这一波打完），随后把钱和只数拼成
一句话显示，`+0x160 = 1`。

## 6. 收尾 `FUN_0052aa50`

```text
钱 += this->+0x65c
角色0.精 -= this->+0x4e0     // 花费，扣到 1 为止
if (this->+0x164 == 2) this->+0x164 = 1
FUN_0044f610(0)              // 回冒险模式
```

## 7. 移植

参考源码 `subgame/KillFlyer/KF_Sys.cpp` 和上面 exe 的读法一致，移植照源码补齐。

- `shared/src/openpal3/states/killflyer.rs`：常数、掷骰、状态和记分，外加 `cost_from_hp`。
  - 苍蝇每局从场地正中 (400, 300) 出发，第一帧先挑目标点（`Reset` 里 `m_isGetNextpt = true`；
    先前出生就把目标设成自己的位置，两根轴都「到了」又不换点，苍蝇根本不飞）；
  - 两根轴各走各的，按帧走 `m_speed` 像素，金苍蝇 ×1.6（`m_specspeed`）；按 60 帧/秒折算 [推断]；
  - 挑目标点时算图角：`acos(dy / (|新方向| + 1))`，分母是长度**之和**（原版笔误，照抄），x 往左取 360 − 角；
  - 命中：拍子那块（鼠标 −(32, 29)，45×45）和苍蝇 32×32 框按原版 `CheckRectOverLap` 判，一下能拍中几只；
    拍子把苍蝇整个罩住反而不算中（原版那个函数只认边跨进去）；
  - 掉落每帧 +0.01 也按帧折算。
- `scripting/sce/commands/killflyer.rs`：界面照 `KF_Sys`——背景场景压暗到 62/255（原版是进来时的定格截图，
  这里场景还在动 [推断]）；开局 2.2 秒闪「减血N」（AssisLang 243，alpha 每帧 −7/+6，6..255）；苍蝇 32×32 转向
  飞的方向，拍中换 `FlyerDie.tga`；拍子 `Kill.tga` / `Kill_pa.tga`（左下角 1:1 裁 64×58）跟鼠标，拍下放 wa040、
  100 毫秒换回；有苍蝇在飞时循环放 wa039；场地里藏鼠标；结束弹 `UI\Flex\Note` 九宫格（0.5 秒余弦缓动从中心
  展开）写「打死苍蝇 N 只 / 获得金钱 M」（258 / 259），点一下离开。手柄 B / Esc 随时离开 [移植]。
- agent：`killflyer` 开一局，`mouse [x, y, 动作]` 发合成鼠标（800×600 坐标，move/down/up/click/rclick）。
