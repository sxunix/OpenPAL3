## 0. 渲染模型（决定怎么理解下面所有矩形）

### 0.1 图片控件（vtable 0x56add0，构造 FUN_004422e0）
- `FUN_00445fa0(rect*)` = SetRect → this+0x10..0x1c。
- `FUN_004426b0(path, useAtlas)` = SetTexture；useAtlas(=DAT_005cefa8) 非 0 时走
  `FUN_0053fcf0`(图集纹理) + `FUN_0053fdd0`(TLI 记录) → 记录指针存 +0x74。
- 绘制 0x442890 → `FUN_00540210(rect, scaledRect, tex, colour, flags, tliRec)`：
  - tliRec != 0：UV 取自记录 (+0x418/41c/428/42c)，四边形尺寸取记录的 w/h
    (+0x410/+0x414)。**贴图按原生尺寸贴在 rect 左上角，不拉伸到 rect。**
  - tliRec == 0：UV = (rectW−0.5)/texW, (rectH−0.5)/texH，同样是 1:1 像素。
  - 所以 exe 里 rect 只是"放置点 + 命中区"，rect 大小和贴图大小经常不一致
    （HeadBk rect 110×95 vs 贴图 115×100；Frame rect 192 宽 vs 贴图 195）。
- 构造默认值：+0x44 文本内边距 = **8**；+0x48 对齐 = 0（1 = 居中）；
  +0x5c 字号档 = 1；+0x4c/+0x50 缩放 = 1.0；+0x94 = −1。

### 0.2 文本（同一控件的 +0x68 字符串，绘制走 FUN_00541160 → FUN_00541210）
- 字号档 +0x5c（`FUN_004427a0(n)`：n==0 → 1，否则 → 2）→ gbPrintFont 表
  `gbGfxManager+0xd0[档]`，字格 F：档0 = 12px，**档1 = 16px**，档2 = 20px，档3 = 24px。
  状态页所有文本控件都调 `FUN_004427a0(0)` → **16px**。
- 排版（FUN_00541210）：
  - 文本区 = rect 四边各内缩 8（+0x44）。
  - 每个字节前进 F/2：ASCII 8px，GBK 汉字 16px。
  - 第 k 行的 y = 文本区.y + F·(k+1)，行距 F=16。字形以该 y 为**底边**。
    → 第 1 行字形占 rect.y+8 .. rect.y+24，即整个内缩带。
    **已用矩形尺寸交叉验证**：所有单行文本控件的 rect 高度都恰好是
    8+16+8 = 32（五灵 150×32、精气神数值 100×32、金钱 (618,−4,738,28)、
    时间 (668,16,748,48)、道具页列表表头 (269,177,645,209)），
    经验块 (10,444,148,508) 高 64 = 8+16·3+8。若 y 是顶边，
    第一行就会越过 `param_2[3] < iVar4` 的溢出判定，这些控件一个字都画不出来。
  - 到 rect.x2−8 自动换行；字面量 `\n` 换行，`\t` 对齐到 8 字节列。
  - 对齐 +0x48 == 1 时水平/垂直居中，状态页未用。
- 32 宽的 rect（等级）内缩后只剩 16px → 每行恰好 1 个汉字 → 竖排。

### 0.3 进度条（vtable 0x56ad64）
- `FUN_0043fec0(rect*)` SetRect（同时写 +0x4c..0x58）；`FUN_0043fa00/fae0` 槽/填充贴图。
- 内边距：+0x84 通用 = 4，+0x88 左 = 1，+0x8c 右 = −4，+0x90 上 = 0(默认)，+0x94 下 = −3。
- 横向、从左到右（+0x44==0, +0x48==0，绘制 0x4401de）：
  - 填充区 x1 = rect.x1 + 左 + 通用 = **x1+5**
  - 填充区 y1 = rect.y1 + 上 + 通用 − 1 = **y1+3**
  - 填充区 y2 = rect.y2 − (下 + 通用) = **y2−1**
  - 满值宽度 (+0x78, FUN_0043fca0) = (x2 − 右 − 通用) − (x1 + 左 + 通用) = x2−x1−5 = **80**（85 宽的条）
  - 当前显示宽度 = 显示值 × (+0x98 = 80/max)。
- 显示值动画（FUN_00440560）：每帧向目标值靠拢 `dt × 36 × speed(+0x70)`。
- 填充颜色 RGB(0x3a,0xcd,0xe2)。填充贴图 (J/Q/S_BarProgress 80×6) 是否按 8 高拉伸 [未验证]。
