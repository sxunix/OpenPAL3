`DAT_00dba251=1`；从冒险模式进来 `+0x6cc=1`，只有这种情况结算时发奖品。
脚本只从冒险模式进，所以移植只做这一支。

## 3D 控件（2026-10-09 查清）

`FUN_00439740` 建控件：载模型 + 新建一台 `gbCamera`、`SetDimention(宽,高)`、
FOV 置 0、`OrthoSize` 默认 3000。**FOV 为 0 就是正交**（gbengine
`gbCamera::SetAsCurrent` 0x10021a8e 的分支），这时半宽 = `OrthoSize`、
半高 = 半宽 × 视口高/宽（`GetViewSizeOnNearPlane` 0x10021a53），所以横竖
的「像素/世界单位」是同一个值 `屏幕宽 / (2·OrthoSize)`。

* `FUN_0043a070(s)`：`OrthoSize = s`。
* `FUN_00439850(a, b)`：把相机摆到世界 (cx, cy, 1600) 看向 (cx, cy, 0)、up=+Y，
  `cx = −(2a/宽 − 1)·s`、`cy = −(1 − 2b/高)·s`。**纵向这一行用的是 `s` 而不是
  半高，原版就是这么算的。** 屏幕是 800×600（`config.ini`，两个全局
  `DAT_00bfd6d0/d4` 由 0x406412 / 0x406440 两处读 ini，缺省 800 / 600）。
* `FUN_0043a090(mode, angle)`：`+0xec = mode`、`+0xfc = angle + 当前角`。
  每帧（0x439a80 一带）：**mode 1 = 持续自转**，`角 += (int)[+0xf4]·dt`，满
  360 归零；mode 2 = 缓动到目标；mode 0 = 不动。
* 自转速度 `+0xf4` 鉴定里三处都写 58（0x525e62 / 0x525ecf / 0x528966）。

鉴定的四台控件（Ghidra 的栈变量里**地址小的是第一个参数**，别读反）：

## 结算（`FUN_00527610`）

```text
score = 0x50
for i in 0..5: if done[i] && correct[i]: score = (score + i*10) * 2
total = score + 剩余放大镜 * 40
```

正文格式串（0x5e90cc）`"\n\n        %s:   %d\n        %s: %d\n        %s:   %d\n        %s:     %d\n"`
依次填 Lang082 剩余秒数、Lang083 放大镜、Lang084 鉴定成功件数、Lang085 总分。
从冒险模式进来时再接 Lang086「获得物品」：一件都没对 →
`"\n\n        %s:   %s"`（0x5e90b4，Lang086, Lang074「无」）；否则先接
`"\n\n        %s: \n\n"`（0x5e909c），再每件对的接
`"        "`（0x5e9090）+ 赝品名 + `"\n"`（0x5d0f44）。这些 `\n` 和 AssisLang
一样是反斜杠加 n 两个字符，由文字控件换行。提示框 (0x116,0x78)-(0x216,0x1a4)，点击关闭
（0x3f1 / 0xaa0c22）时把每对答对的**赝品**（6301–6305）各加 1 件进背包
（`FUN_0040ccf0`），然后 `FUN_00527f50(3)`。gdb 里赝品的名字是真品名加
「赝品」（6301 = 兽面纹爵赝品），结算单里列的就是这个。

## AssisLang.lang / .dft 的读法（`FUN_00457410`）

**槽位怎么定**（2026-10-09）：`FUN_00457410` 把每条 `strncpy` 进一块 0x100 字节的
格子、依次往后挪，所以表是「基址 + 下标·0x100」。基址用一个锚点反推：exe 里
`&DAT_00dc733c + 角色号·0x100`（0x49d... 一带）是五个主角名，而表里第 64–68 条
正好是景天/雪见/龙葵/紫萱/长卿，于是

```text
LangN 的缓冲区 = 0xdc733c + (N − 64) · 0x100
```

反过来，遇到 `DAT_00dd????` 这种 0x100 对齐、低位 0x3c 的字符串地址，
`N = 64 + (地址 − 0xdc733c)/0x100` 就能查出它是哪一条。
这张表共 400 条，解析后的下标就等于 `LangNNN` 的编号。
（头一个用法：买卖页的 `DAT_00dd4a3c` = Lang279「没有人可以装备」。）

tokenizer `FUN_00431a60`：空格、Tab、逗号、换行分词；`;` 起注释到行尾；
`$…&` 是字符串体，在分词层整个跳过。读法：找到 `Begin` 后的节名（这里都是
`sec1`），然后循环：取下一个词，等于 `end`（不分大小写）就停，否则再读一个
`$…&` 字符串 `strncpy` 0x100 字节进第 i 槽——**下标是出现顺序**，`Lang081`
这种名字里的数字不参与。字符串里的 `\n` 是两个字符，显示时才换行。

用到的条目：74 无、81 要玩鉴定游戏吗？、82 剩余时间、83 剩余放大镜、
84 鉴定成功、85 总分数、86 获得物品、195 鉴定失败。
