# `cbdata\pal3_softstar.gdb` —— 游戏数据库

PAL3 的物品、仙术、合击技、战斗角色（含主角与全部怪物）四张表，全部在这一个
文件里。原版由 `Fight\LoadData.cpp`（脱壳 exe 里的 `FUN_00478e00`）一次读入。

已实现：`yaobow/fileformats/src/pal3/gdb.rs`（`cargo test -p fileformats --lib pal3::gdb`）。

## 出处与许可证

字段级布局移植自 **Pal3.Unity** 的 `Pal3.Core/DataReader/Gdb/`
（`GdbFile.cs` / `GdbFileReader.cs`），Copyright (c) 2021-2025 Jiaqi (0x7c13) Liu，
GPL-3.0，<https://github.com/0x7c13/Pal3.Unity>。yaobow 同为 GPL-3.0，移植合规，
源码里已保留署名。

**四个记录长度是独立核对过的**：`FUN_00478e00` 里四次 `gbVFileSystem::Read` 的
每元素字节数分别是 `0x354 / 0x2f8 / 800 / 0x278`，与移植后的结构体逐字节吻合
（`record_sizes` 测试）。

## 文件结构

```text
0x00  char[128]  "__PAL(Softstar_Ltd: Cool_J)_GameDataBase_OutFile__"
0x80  u32 u32    战斗角色表：文件偏移、记录数
0x88  u32 u32    仙术表
0x90  u32 u32    物品表
0x98  u32 u32    合击技表
```

记录定长紧密排列。v1.4 简体中文版实测：

| 表 | 偏移 | 记录数 | 记录长度 |
|---|---|---|---|
| 战斗角色 | 0xa0 | 167 | 852 (0x354) |
| 仙术 | 0x22c6c | 187 | 760 (0x2f8) |
| 物品 | 0x45794 | 408 | 800 |
| 合击技 | 0x95294 | 10 | 632 (0x278) |

四张表首尾相接，最后一张表的末尾 `0x96b44` 正好是文件长度 617284，没有空洞。

文本字段是定长 GBK 缓冲，以第一个 NUL 结束。

## 抽取文件

```sh
cargo run -p packfs --example pal3_probe -- <PAL3 目录> \
    --dump /basedata/basedata/cbdata/pal3_softstar.gdb /tmp/pal3_softstar.gdb
```

带真机数据跑测试：

```sh
YAOBOW_PAL3_GDB=/tmp/pal3_softstar.gdb cargo test -p fileformats --lib pal3::gdb
```

## 表里有什么

- **战斗角色**：等级、精气神武防速运、五灵、经验、掉落、可偷钱/物、尸块与其触发
  技能、逃跑率、会的 3 个普通仙术 + 1 个 Boss 技、普攻打行还是打列
  （916/917/921/922/926/927 打行，918/919/920/923/928 打列）、
  迷宫 AI 四档（高度 / 游荡范围 / 索敌范围 / 移动与追击速度）。
- **仙术**：五灵属性、可用主角、目标范围、12 项属性影响（值 + 绝对/百分比/回满/加上限）、
  31 种战斗状态影响、气/神/特殊消耗、成功率档、升级所需使用次数、下一级法术 ID、
  能否战斗外使用、可合成的法术及其条件。
- **物品**：价格、古董价、类型（治疗/投掷/仙宝/古董/矿石/剧情/衣帽鞋饰/武器/尸块）、
  武器类型、可用主角、使用地点、属性与状态影响、装备属性
  （省气/省神/暴击加成/特技成功率/连击数）、尸块炼制（矿石 → 成品）、两材料合成。
- **合击技**：参与主角、每人要求的五灵站位（含"风火雷任意""水火土任意"）、
  武器要求、战斗状态要求、发动的技能 ID、目标范围。
