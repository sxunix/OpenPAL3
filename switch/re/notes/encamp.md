## 3D 部分

### 相机（`FUN_0047c640` / `FUN_0047c830`）

gbCamera FOV 50.0（`+0` 是整角，`GetViewSizeOnNearPlane` 用
`zNear·tan(FOV·π/360)` 算半宽），zNear 50、zFar 6000。极坐标模型
`FUN_0047c830(1)`：

```text
dir = (sin yaw·cos pitch, sin pitch, −cos pitch·cos yaw)
eye = target − dist·dir
```

初值 target (0,20,0)、dist 700、yaw 603°（=243°）、pitch −12°，算出
**eye ≈ (610, 165.5, −310.9) 看 (0,20,0)**。移植用 `set_fov43(50°)` 是
`[推断]`——原版 50° 是横向整角，这里当成 4:3 下的横向 FOV 用。

## UI（`FUN_0052ba10` 构造，`FUN_0052beb0` 摆控件，800×600）

### 贴图控件的画法（`FUN_005400e0`）

顶点 NDC `{x0 = 2l/W − 1, yBottom = 1 − 2b/H, x1, yTop}`，uv
`{0, 0, (w−0.5)/texW, (h−0.5)/texH}`；gbengine 的 TGA 读取
（`gbImage2D::LoadImageFile` 0x1001e490 → 0x1001ed50）对左下原点的文件
（描述符 0x08，这里全部都是）不翻转。合起来：**一个 w×h 的控件显示贴图
左下角 w×h 那块，正立，1:1 贴在矩形里**（正常朝向的图上 uv0 = (0, 1−h/H)
在上、uv1 = (w/W, 1) 在下）。用 PIL 按这条规矩合成过一张，转盘、四个头像、
指针、说明牌全部正立对齐。

贴图内容范围（左下角）：TurnTable 512² 内容 x0..415、y102..511；Pointer
64×256 x1..45、y64..196；head 128² x0..70、y57..127；Remark 1024×256
x0..542；BlanceHead0/2/3 64×128、BlanceHead1/4 128×128；BarBk 128×16 内容
76×12；JingProgress/ShenProgress 128×8 内容 70×6；JingText/ShenText 32² 内容
22×19；BlanceBk 256² 内容 192×255。

### 旋转贴图控件（指针，`FUN_00442e10`，vtable `PTR_FUN_0056ae10`）

字段：+0x98 角度、+0x9c 模式、+0xa0 目标、+0xa4 速度、+0xa8 方向、+0xac
停止、+0xb0 加速度、+0xb4 初速。渲染（0x442e90）绕矩形中心在像素空间转
（`T(c)·S(1/8,1/6)·R(a)·S(8,6)·T(−c)`，正角逆时针 `[推断：按标准旋转公式]`）。
更新（0x442ff0）模式 2：方向 0 → `angle += speed`，>359 归 0；**方向 1（宿营
置 `+0x5c8` = 1）→ `angle −= speed`，<0 → 359.0**，指针顺时针转。速度是
**每次更新（每帧）的度数**，不乘 dt。

### 进度条控件（`FUN_0043f7f0`，更新 0x440560）

矩形 +0x10..0x1c；边距 2/2/2/1（`FUN_0043fd90(2)/fdc0(2)/fdd0(2)/fde0(1)`）；
轨道像素 `+0x78 = (r−4) − (l+2)` = 76 px 条是 **70 px**；最大值 +0x7c，
比例 +0x80 = 70/max；目标像素 +0x74 = 值·比例；当前像素 +0x6c；每次更新
`cur += dt·36.0·speed`（speed = 1.0，即 36 px/s）直到目标；`+0x9c =
cur·max/70` 是显示值；`+0xa0` 在到达后的那一帧为 1。

## 流程（`FUN_0052c480` 每帧，`FUN_0052ca10` 消息）

1. 进入 `FUN_0052c8a0`：说明牌可见，转盘/指针/面板隐藏，pct `+0x27c8` = 0，
   `+0x27cc = 1`（加速中），速度 `+0x27d0 = 0`，上限 `+0x27d4 = 5.0`。
2. 点说明牌（0x3f1 / 0x0080ac07）→ 隐藏说明牌和文字，显示过场框（kind 3）。
3. 过场框事件 2 且 `!+0x3290` → 显示转盘和指针，`+0x484 = 1`，指针模式 2
   方向 1，放 `wa033` 循环，`+0x3290 = 1`。
4. `+0x484` 时每帧：`dv = dt·36.6·0.08`；加速：`speed += dv`，封顶 5.0；
   减速：`speed −= dv`，到 0 为止；指针速度 = speed；停止标志 `+0x5cc =
   (speed ≤ 0)`。没停：`+0x27d8 = 0`。停了：按扇区算 pct，`+0x484 = 0`，
   `+0x27d8 = 1`，`+0x27de = 1`。
5. `FUN_0052d5b0()` 每帧把四个头像槽 `+0x838..+0x844` 重新随机
   （`rand()%5`，不在队的重抽）。
6. 点转盘（0x0080ac01）：若 `+0x485 && !+0x486` → `+0x487 = 1`（退出）；
   否则若 `!+0x27d8` → `+0x27cc = 0`（开始减速），`+0x484 = 1`。
7. `+0x27de`：停 `wa033`，最后一次 `FUN_0052d5b0`，结算 `FUN_0052d230`，
   `+0x27de = 0`。结算末尾显示结果框（kind 0）。
8. 结果框事件 0（点「是」）→ `FUN_0052d0f0` 显示面板：在队角色各一块，
   `FUN_0043fe90` 复位条，`FUN_0043fca0(max精, max神)`，条速度 1.0，
   `FUN_0043fdf0(cur精, cur神)`；`+0x485 = 1`。
9. `+0x485` 时每帧写每块面板的 "%d/%d"（`ROUND(条+0x9c)` / max）；若
   `+0x486 && 精条+0xa0`（走到头）→ `+0x486 = 0`，之后点转盘退出。

### 扇区 → 百分比

`f = 360 − angle`：f ≤ 180 → 0；180 < f ≤ 270 → 30；270 < f ≤ 318.6 → 50；
318.6 < f ≤ 354.2 → 75；354.2 < f ≤ 359 → 100；f > 359 保持上一次（初值 0）。
换成角度：[1, 5.8) → 100（12 点左边那道红）、[5.8, 41.4) → 75、[41.4, 90)
→ 50、[90, 180) → 30、[180, 360) → 0、(0, 1) 不变。TurnTable.tga 里 12 点
逆时针依次是红、黄、橙、紫（左半），右半全蓝，与这张表一致。

### 结算 `FUN_0052d230`

`FUN_0052d200(k)`：四个头像槽全是 k 且 k 在队 → 「大满贯」。

* 景天(0)/长卿(4) 大满贯：精/气/神当前值 `+0x3cc/3d0/3d4` = 上限
  `+0x39c/3a0/3a4`；文字 `"\n          %s%s"`（名字，Lang154「精气神全满」）；
  音效 `wd003`。
* 雪见(1)/龙葵(2)/紫萱(3) 大满贯：`cur精 = ftol(pct·0.01·max精 + cur精)`；
  好感 +10（`DAT_00c04334[6]`，基数 20）；文字 `"\n            %s%s+10"`
  （名字，Lang155「好感」）；音效 `wa009`。
* 然后每个在队角色：`cur精 = ftol(pct·0.01·max精 + cur精)`，12 项当前值
  `+0x3cc..+0x3f8` 按 −0x30 处的上限截断（负数归 0）；循环里每次放 `wd001`
  （五次，不管在不在队）。
* 接 `"          %s%s%s%d%%"`（Lang185「全体」、Lang156「恢复」、Lang14
  「精」、ftol(pct)）→「全体恢复精NN%」；有大满贯时前面先有 `"\n"`。
* 设文字，显示结果框（kind 0），`FUN_0040be80(0)` 再按在队角色截断一遍。

角色表 `DAT_00c043a0` 步长 0x580：max精 +0x39c、max神 +0x3a4、cur精
+0x3cc、cur神 +0x3d4。Lang 条目（`AssisLang.lang`，顺序下标）：14 精、
64 景天、65 雪见、66 龙葵、67 紫萱、68 长卿、154 精气神全满、155 好感、
156 恢复、185 全体。

## 移植侧

* `openpal3/encamp.rs`：扇区表、指针/进度条的步进、结算公式、大满贯判定、
  版面常量、文字，带单元测试。
* `scripting/sce/commands/encamp.rs`：`SceCommandEncamp { site }`。压一个
  `CoreScene`：Encamp_Scene.pol + 旗子 pol + 五个在队角色（c09 循环，
  `MV3_SCALE`），相机按上面的极坐标摆；说明牌/转盘/指针/头像/面板走 imgui，
  贴图按「左下角 w×h、正立」的规矩取 uv。对话框和名字框没有贴图，画框。
* 跑图（`fast_forward`）时按 pct 0 直接结算退出，不写好感。
* `tests/pal3_encamp.rs`：实机数据核 rmk 文字、Lang 条目、pol/贴图存在。
