## 1. 界面对象与状态

模式 2 的界面对象：构造 `FUN_004590d0`、布局 `FUN_004593c0`、虚表 0x56b394。

- `+0xcb8` 是当前状态，`FUN_0045a220(n)` 切换：0 前台菜单、1 买装备（子页 `+0xcbc`）、
  2 买道具（`+0xcc0`）、3 卖（`+0xcc4`）、4 退出（恢复音乐）、5 全部藏起。
- 绘制 `0x45a490`：先 `0x459900` 画背景（`+0xcc8` 那张场景截图，白色调、alpha 0x3e，
  铺满 `+0x50..+0x5c` = 全屏），再按 `+0xcb8` 画菜单或子页。
- 事件 `FUN_0045a600`（id 0x3e9 = 按钮点击）：

| 按钮 id | 字（AssisLang 槽） | 动作 |
|---|---|---|
| 4 | 262「买装备」 | `FUN_0045a220(1)` |
| 5 | 263「买道具」 | `FUN_0045a220(2)` |
| 6 | 264「卖东西」 | `FUN_0045a220(3)` |
| 7 | 163「聊 天」 | `+0xa0` 非 0 才动：`FUN_0045a220(4)` + `FUN_00432170(+0xa0)` 跑商人过程 |
| 8 | 166「退 出」 | `FUN_0045a220(4)` |

  每次点都播 `wa001`。

## 2. 前台菜单（`FUN_004593c0` + `FUN_00459970`）

构造里写死锚点：`+0x80 = 90`（行宽）、`+0x84 = 24`（行高）、`+0x88 = 360`、`+0x8c = 136`。

- 幡头 `FlagT`：`(360, 136, 428, 168)`。
- 第 k 个按钮：`(350, 168 + 24k, 440, 192 + 24k)`，贴 `rawbtn`，字色 RGB(0x0c,0x1f,0x00)。
- 按钮后面的幡身 `FlagM`：按钮 rect 左上各 +1、宽 86、下边 −1。
- 幡尾 `FlagB`：接在最后一个按钮底边，`(360, 底, 428, 底 + 11)`。

### 三段条（`FUN_0043d830` 构造，虚表 0x56acfc，绘制 0x43d940）

`FUN_0043dc40(a, b)` 写 `+0x44 = a`、`+0x48 = b`；`+0x50` 是方向（0 横 1 竖）。横向：
左端头 `(x1, y1, x1+a, y2)`、中段从 `x1+a` 起每 `a` 一块平铺到 `x2−a`（最后一块不裁、
被右端头盖住）、右端头 `(x2−a, y1, x2, y2)`。每块在贴图上取第 0/1/2 列、宽 `a`
（`0x43dab0`：u = 列 × a / 贴图宽）。

### 选中行上的东西（买装备页事件 `0x46c5dd` 起）

`FUN_0043ebb0(列表, 行)` 返回行锚点 `(列表.x1, 列表.y1 + (行 − 顶行) × 23)`。

- 「持有:N」提示（`+0x19aec`，`"%s:%d"`、Lang44）：`(锚x+90, 锚y, 锚x+180, 锚y+32)`，
  N = `99 − 可买数`，也就是背包里已有几个。
- 加减钮：`+0x1884c` 起是一个小部件（两个 rect、「减」`+0x1886c` id 0x195、「加」`+0x189c4`
  id 0x196，宽 24、高 40、`+0x18b24` 排法、`+0x18b28` 间隔 20）。排法 1（初值）：「加」在
  `(锚x+200, 锚y−4)`，「减」在它右边再隔 20；排法 0 两个对调。可买数为 0 时两个都置灰。

原版一单可以在好几行上各挑数量，「累计」是整单的钱，确定时一起结（卖页每类各有一个
累计，`shop.md` §5.1）。

## 6. 买装备页左边的对比面板

控件在 `FUN_0045b990` 里建，头像由 `FUN_0045b200/b320/b440/b560/b680`（每人一个，参数是显不显示）排，
其余由 `FUN_0045e9f0` 排；比较在 `FUN_004623a0`，箭头跳动在 `FUN_0046b040`。数值用
`switch/re/layout_trace.py 45e9f0 8194 66ec=1 668c=68 6690=32 6694=133 6698=118` 核过。

### 6.1 头像

`FUN_0045a7b0`：`+0x66dc` = 68，`+0x66e0` = 屏高/4 = 150，`+0x66e4/+0x66e8` = 65×86。
显示的人（`+0x66ec+i` 非 0）按角色号从小到大数第 k 个：

    head = (68, (150−86)/2 + 150k, 133, … + 86)      // y = 32, 182, 332, 482

贴图 `GameMainUI\Communal\AttFrameHead{i}.tga`（65×86，图集第 4 页）。`FUN_00459fa0` 设显示标记，
已有四个再加就不显示——最多四个 [推断：标记来源是队伍，没追到调用方]。

### 6.2 大图标、小图标、箭头（相对头像 (x,y,x2,y2)）

- 大图标：衣/武器/饰品一在左 (x−24, y+36)，帽/鞋/饰品二在右 (x2+18, y+36)。
  控件 `+0x14618 + i*0x438 + k*0xb4`，k = 衣、武器、饰品、帽、鞋、饰品。
- 小图标：头像下一排，(x−6+18k, y2)，k = 衣、帽、鞋、武器、饰品、饰品（`*_small.tga`）。
  控件 `+0x15b30 + i*0x390`。`FUN_00469eb0`（买下后穿上）把对应那格点亮；进页时的初值没追，
  移植端按「那格穿着东西」[推断]。
- 箭头：每人六组（组号 = 衣 0、武器 1、饰品一 2、帽 3、鞋 4、饰品二 5，控件 `+0x66f4 + i*0x1c80 +
  组*0x4c0 + n*0x98`，n = W/S/F/Y_up、W/S/F/Y_down），每组四个格：

      左边组：左上 (x−30, y+12)  右上 (x−2, y+12)  左下 (x−30, y2−38)  右下 (x−2, y2−38)
      右边组：左上 (x2+4, y+12)  右上 (x2+32, y+12) 左下 (x2+4, y2−38)  右下 (x2+32, y2−38)

  贴图 22×23（图集第 3 页）。

### 6.3 比较（`FUN_004623a0`，按 gdb `+0x264` 物品类型分 7 衣、8 帽、9 鞋、10 饰品、11 武器）

对每个显示的人，只有这件装备他能穿（`+0x266+i`）才比：身上那一格（`DAT_00c046fc + i*0x580` 起每格 12 字节，
帽/衣/鞋/饰一/饰二/武器）没穿就跟 0 比，穿了跟那件比。四项按这个顺序：

    武 +0x28a（attribute_impact_value[3]）   速 +0x28e（[5]）   防 +0x28c（[4]）   运 +0x290（[6]）

大了亮 `X_up` 放上一行，小了亮 `X_down` 放下一行，相等不亮。格子的分配：武去左格并记占位；
速在左格空着时去左格、否则右格（不记占位）；防去右格并记占位；运在右格空着时去右格、否则左格。
（占位标记在 `+0x10474 + i*0x30`。所以武、速、防同时涨时速和防叠在右上——照原样。）
饰品两格各比一次，左右两组都亮。最后把这一类的大图标点亮。

### 6.4 箭头跳动（`FUN_0046b040` → `FUN_00478880(1,1,1)`）

每个箭头的周期字段写 0x24 = 36 ms；往返模式下每 36 ms 挪 1 像素，从原位挪到目标 rect（y − 12，
`FUN_0045e9f0` 末尾的 `+0x10658` 表）再挪回来。上下两行都往上跳。

## 7. 移植端的取舍

- 背景：原版打开时 `FUN_004bdc40` 把场景按 512×384（`gbCamera::SetDimention(0x200, 0x180)`）
  渲染进一张渲染目标，之后每帧用白色、alpha 0x3e 拉满全屏叠一次。24% 的叠图只有在底下场景
  照常画时才有意义，所以效果是场景上一层淡淡的虚影、不是压暗 [推断]；移植端不加这一层，
  场景照常画。（第一版按「压暗」做了一层 76% 的黑，已撤掉。）
- 默认字色：控件基类 `FUN_00445aa0` 把 `+4` 设成 0xff050500（近黑）；页面里商人的话、「持有」
  「累计」都没另设，移植端统一用列表那个暗绿 RGB(0x0c,0x1f,0x00)。
- 选中行：`ListBoxSelPic` 本身是不透明的深绿条（均值约 RGB(13,32,27)），暗绿字压在上面看不清。
  列表控件画行的那段没追到（虚表 0x56ad64 的 1 号槽 `0x43ff70` 画的是滚动条），移植端把
  选中行的字换成 0xfffafa [推断]。页面给列表写的 `+0x488/+0x48c/+0x490 = −4/−6/10` 还没对上用途。
- 按钮字居中 [推断]：按钮控件的对齐方式没逐字段读。
- 三态按钮 0 常态 / 1 悬停 / 2 按下，照其它页面的约定。
- 进买页时说 `EntryBuy`、进卖页说 `EntrySale`；`BeginTalk` 在 exe 里读它的地方没找到，没画。
- 进卖页前按背包重排一遍，刚买的东西马上能卖。卖页加减钮的位置照买页的偏移放 [推断]：
  卖页那一段没逐字段读，它压在「数量」「持有」两列上。
- 离开钮和「取消」回前台菜单（原版子页的 Exit 事件没逐字段读）[推断]。
- 手柄：十字键上下选行、左右调数量，A 确定，Y 还价，X 换卖页页签，B 返回。
- 对比面板照 §6 做了；箭头的钟在换选中行时归零 [推断：原版在换物品时重置控件]。
- 没做：3D 预览、滚动条（列表跟着光标滚）、按钮音效、买装备后问穿不穿。
