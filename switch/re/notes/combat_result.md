- 打赢 / 逃掉时在散场开始那一刻结算（写回、经验、钱、物品），同时收集升级 / 钱 / 物品
  消息；按上表的时间轴画，确定键跳过能跳的步骤，走完才散场。
- 散场镜头（`combat_camera.md`）和这条时间轴同时走。
- **[推断]** 名字 / 等级写在 (0,211) 那一行；面板滑入速度按 3000 px/s；得到横幅用
  getitem.tga；物品音效改在显示时放。

  - `use_skill` 升了级的排「仙术升级」；
  - 横幅按 `result::magic_row`（单一五灵进那一行，两个以上进「双」`[推断：往库里放仙术的
    代码没找到]`）；
  - 六个数 = 每行仙术的 `uses` 之和；画法 2026-09-14 查清：`FUN_0051c330` 建控件时颜色设 0xffffffff（0x51c5dc）、`FUN_004427a0(0)` 16px，`FUN_005184e0` 用 `FUN_004427c0(文字, 0)` 写（`+0x48` = 0 不居中），文字控件渲染 0x442a40 → `FUN_00541160` 从 rect 左上角缩内边距 8（`FUN_004422e0` 的 `+0x44`）开始写；`FUN_00541210` 最后一参 = 1 才居中（宽按 字数 × 字号/2）。不滚动（`FUN_00519080` 那条滚动挂在别的控件上）；
