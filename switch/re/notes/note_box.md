# PAL3.exe v1.4 — 提示框（SCE 68 / 157）逆向笔记

68 `UIDisplayNoteCommand`（`0x437170`）和 157（`FUN_00410360`）用的是同一个控件：场景界面
里的常驻对象 0xdba134。实现在 `yaobow/shared/src/scripting/sce/mod.rs` 的 `render_note`。

## 建立（`FUN_00450b30`，场景界面初始化 `0x44f130` 一带调用）

```text
父 rect = ((屏宽 − 0x112) / 2, 10, 同 + 0x112, 0x57)   // 800 宽时 (263, 10, 537, 87)
FUN_00445b90(0, 父 rect, 父窗口)
FUN_004450a0(1, 父 rect, this, "ui\flex\note")       // this+0x48：九宫格子控件
FUN_00445910(2)                                     // 字号档 2
隐藏
```

## 显示（`FUN_00450bc0(文本)`）

- 九宫格子控件的 rect = `(0, 0, max(0x40, (strlen + 5) × 10), 0x30)`（strlen 是 GBK 字节数）；
- `FUN_00445db0(this)`：在父 rect 里居中，所以框的顶边是 `10 + (77 − 48) / 2 = 24`，横向居中
  ——**在屏幕上方，不在正中**；
- 写字、计时 `+0x108 = 0`、显示、`FUN_00445930(1)` 把模式 `+0xac` 设成 2。

## 每帧（`FUN_00450c90`）

模式 2 时 `+0x108 += dt`，超过 **4.0 秒**就直接隐藏——没有淡出。

## 画（九宫格控件 `FUN_00445500`）

- 角块边长 = min(贴图边长 `+0xb8`（note0 是 32）, 框宽的一半, 框高的一半)，框高 48 时是 24；
  贴法同对话选择框（0 左上、1 左下、2 右下、3 右上、4 左、5 下、6 右、7 上、8 中）；
- 模式 2 且有字时 `FUN_00541160(文本, 框 rect, +4 颜色, 字号档 +0xb4 = 2, 对齐 1)`：
  20px、居中。
- 字色：`FUN_004450a0` / `FUN_00450b30` / `FUN_00450bc0` 都没设，exe 里也找不到直接写
  0xdba180（子控件 `+4`）的指令，按代码看是基类 `FUN_00445aa0` 的默认 0xff000505（近黑）。
  可 `note8` 是纯黑、alpha 207，近黑字压上去看不见，原版不会这样——颜色一定另有地方设
  （可能是构造时按相对偏移写的），没追到。移植端先用对话选择框的 0xfffafa [推断]。

## 移植端原先的问题

放在屏幕正中、imgui 小窗样式、按 Pal3.Unity 的 2.5 + 1 秒淡出——三处都和原版不一样。
