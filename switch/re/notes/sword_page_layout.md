+ capstone 反汇编（`switch/re/x86dis.py`）。所有坐标均为 800×600 原生像素。
标注 [推断] 的条目未在代码里 100% 闭环，其余均直接读自指令。

## 4. 五灵控制盘（右侧，取代队伍牌）

| 元素 | rect | 贴图 | 原生 |
|---|---|---|---|
| Sword\wulingControl.tga (+0x2b6dc) | **(690,131,795,519)** | | 109×386 |

盘内每个五灵有 **两个按钮**（阴 `lunar` / 阳 `Positive`），共 10 个，
外加 5 个 `perfect` 覆盖层。每个按钮建法相同：

- 三态按钮：`vtable+0x1c(id, rect, page, 基名, 0)` → `<基名>0/1/2.tga`，42×52；

  rect 由前一个按钮 **(x1−7, y1+1)** 推出、同为 43×51。

## 9. 一处与仙术有关的采集

init 里有一段循环（0x4ac6d3 起）：

```
n = FUN_004790f0()                      // 全局技能表 0x975ed8 的条目数
for i in 0..n:
    e = FUN_00479080(FUN_00479100(i))
    if *(byte*)(e + 4) == 4:            // SkillType == 4 (WeaponMagic 武器技)
        memcpy(this + 0x224 + k*760, e, 760)   // 760 = gdb SkillInfo 记录长度
        k++
```

即**本页把全部 `SkillType == 4`（武器技/剑术）的技能收集到 `this+0x224`**，
每条 760 字节，正是 gdb `SkillInfo` 的记录长度。
数据库里 type 4 共 24 条，且几乎都带 2 种以上五灵属性
（`风刃裂地` 风+土、`幻水惊雷` 水+雷、`天地元灵斩` 五灵齐全 …）。

[推断] 御剑页的目标就是**把装备投进龙晶石以调整魔剑的五灵阴阳，
从而解锁这些多属性武器技**；`perfect` 状态对应某一元素阴阳皆满。
